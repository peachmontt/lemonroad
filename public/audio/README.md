# Audio files (optional)

The game uses **Web Audio API** synthesized sounds by default — no files required.

To swap in real MP3/OGG clips later, wire them in `src/game/audio.ts` and place files here:

| File | Used for |
|------|----------|
| `scream.mp3` | death / rug pull |
| `slip.mp3` | lemonade spill |
| `lemon.mp3` | bull run |
| `error.mp3` | market crash |
| `kazoo.mp3` | dancing lemon |
| `knife.mp3` | knife event |
| `bonk.mp3` | IRS taxman |
| `start.mp3` | game start |
